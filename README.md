### Quick Start
1. **Start Backend**:
   ```bash
   cd ecovision-ai/backend
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
2. **Start Frontend**:
   ```bash
   cd ecovision-ai/frontend
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
